# Streets, Not Reputations

219 European cities ranked by cycling risk — measured from 67 million road
segments of the Defensive Pedal production risk model, validated against 1,169
serious cycling injuries and 2.6 billion measured cyclist passages.

Live site: https://victorwho.github.io/european-cycling-risk-ranking/
