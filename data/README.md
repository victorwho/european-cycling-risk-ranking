# Open data supplement

- `eu300_city_index.csv` — EU-300 edition, one row per city: rank, index, 90% rank
  interval, tier and stability, the three normalised dimension values and
  per-dimension ranks, and the raw dimension inputs (street risk per km,
  high-risk share, journey risk mean/p90, access composite, locked population
  share, low-stress km, street km, population).
- `eu300_criterion_panel.csv` — the 18-city criterion panel joining EU-300 index
  values to measured serious-injury rates per cyclist passage (outcome data
  derived from public counter and crash sources).
- `eu300_criterion_panel_public_counters.csv` — the same panel restricted to counters run
  by public authorities (12 cities), the robustness check in the paper.
- `eu219_city_index.csv`, `eu219_criterion_panel.csv` — the same files for the
  first (EU-219) edition, kept unchanged.

All four are generated by `tools/build_data.py`; `--check` verifies a committed
edition reproduces from its results.
