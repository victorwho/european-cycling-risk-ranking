# Open data supplement

- `eu219_city_index.csv` — one row per city: rank, index, 90% rank interval,
  tier and stability, the three normalised dimension values and per-dimension
  ranks, and the raw dimension inputs (street risk per km, high-risk share,
  journey risk mean/p90, access composite, locked population share, low-stress
  km, street km, population).
- `eu219_criterion_panel.csv` — the 17-city criterion panel joining index
  values to measured serious-injury rates per cyclist passage (outcome data
  derived from public counter and crash sources).
